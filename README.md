# Kalkulator Pintar Sales – Program November 2026

Web app interaktif (satu file `index.html`, tanpa instalasi) untuk sales mensimulasikan order berdasarkan dokumen *Program & Harga Nett November 2026*.

## Fitur
- **Simulasi Order** – pilih channel (Retail / Gromin-Grosir-TDP / SO), area GRSM, outlet GMM, transaksi pertama; isi qty per SKU → harga nett, diskon invoice, bonus produk, total hemat.
- **Rekomendasi pintar** – saran "tambah X ctn" untuk naik tier diskon / dapat bonus, plus program lain yang berlaku dan belum dipakai (sekali klik untuk menambah).
- **Program Berlaku** – daftar semua program, disaring sesuai channel & area, dengan sisa hari periode.
- **Ikat Target TPH** – hitung target per zona, cashback & bonus, serta rekomendasi naik zona.
- **Cashback Galon 15L** – estimasi cashback bulanan & tier berikutnya.
- **Price List** – semua SKU per channel + Aspen.
- Salin ringkasan / kirim via WhatsApp.

## Cara pakai
Buka `index.html` di browser (bisa juga di-hosting lewat GitHub Pages).
